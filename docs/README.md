# QuarryAI Documentation

This folder contains the project documentation for the QuarryAI website and public-facing project materials.

## Documentation overview

These docs are intended to help Minecraft server owners, developers, and contributors understand what QuarryAI is, how Paper plugins work, how plugin installation generally works, and how to troubleshoot common issues without making unsupported claims.

## Recommended reading order

If you are new to the project, start here:

1. [../README.md](../README.md) — repository overview and project description
2. [paper-plugin-guide.md](paper-plugin-guide.md) — what Paper plugins are and how they fit into Minecraft server development
3. [plugin-installation.md](plugin-installation.md) — safe installation steps for a server plugin
4. [minecraft-plugin-ideas.md](minecraft-plugin-ideas.md) — example plugin ideas for Paper servers
5. [troubleshooting.md](troubleshooting.md) — common plugin and server issues
6. [seo-and-brand.md](seo-and-brand.md) — repository branding and consistency guidance

## Project scope

The repository currently contains a public static website and documentation materials. It does not contain a full Java plugin codebase or an independently verifiable plugin generator implementation in this snapshot. These docs are written to describe the actual project accurately and to make it easier for people to understand the product and its purpose.

## 🚀 Overview

QuarryAI simplifies Minecraft server administration by removing traditional development roadblocks. Users can skip local Java compiler configurations, IDE installations, and Maven/Gradle build chains, generating working `.jar` binaries directly through an online interface.

## ✨ Core Features

* **Natural Language to Code:** Translate gameplay mechanics or command requirements into fully mapped Java classes.
* **Model Choice:** Support for multiple language models (including Gemini and ChatGPT integration options).
* **Instant Compilation:** Directly build and package verified source trees into executable plugin binaries.
